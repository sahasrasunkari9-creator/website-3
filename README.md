# 🍽️ THE SPICE TABLE
### A Premium Restaurant Website Experience

**THE SPICE TABLE** is a modern, elegant restaurant website designed to deliver a premium dining experience online. It features a visually appealing interface, interactive food menu, restaurant gallery, customer reviews, and convenient reservation and ordering interfaces.

🌐 **Live Website:** https://website-3-shr4.vercel.app/

---

## ✨ Features

- 🎨 **Premium UI/UX:** Elegant layout with a modern, cinematic visual experience.
- 🎬 **Animated Hero Section:** Eye-catching animations and atmospheric visual effects.
- 🍲 **Interactive Food Menu:** Browse dishes, search for food, and filter menu items by category.
- 🖼️ **Restaurant Gallery:** Explore food and restaurant imagery in an interactive gallery.
- ⭐ **Customer Reviews:** A dedicated section showcasing sample customer testimonials.
- 📅 **Reservation Form:** An interface for entering restaurant reservation details.
- 🛒 **Shopping Cart:** Add dishes to your cart, update quantities, and review your selections.
- 🚚 **Checkout Interface:** Explore demo delivery and pickup ordering flows.
- 📱 **Responsive Design:** Designed to adapt to desktop, tablet, and mobile screens.
- 💌 **Newsletter Form:** An interface for newsletter subscriptions.

---

## 🛠️ Technologies Used

- **React.js** — Building interactive user interfaces.
- **Vite** — Fast development server and build tool.
- **JavaScript (ES6+)** — Application logic and interactivity.
- **CSS3** — Styling, animations, layouts, and responsive design.
- **LocalStorage** — Persisting shopping cart data in the browser.
- **Unsplash Images** — Food and restaurant imagery.

## 🚀 Getting Started

Follow these steps to run the project locally.

### Prerequisites

Install the following on your computer:

- Node.js and npm
- Visual Studio Code
- Git (optional, for version control)

### 1. Clone the Repository

```bash
git clone https://github.com/sahasrasunkari9-creator/website-3.git
```

### 2. Open the Project Folder

```bash
cd website-3
```

### 3. Install Dependencies

```bash
npm install
```

### 4. Start the Development Server

```bash
npm run dev
```

Open the local URL displayed in your terminal to view the website.
